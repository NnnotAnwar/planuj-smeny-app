## How to review (morning)
Each branch is an independent, PR-able unit. To look at one:
```bash
git checkout feat/announcements   # etc.
git log --oneline master..HEAD    # the commit
```
The backend pattern is identical across all of them, so once you read one
(`src/features/announcements/`) you understand them all: `types.ts` (Zod shape),
`*Service.ts` (talks to Supabase), `use*.ts` (React-Query hook the UI calls).
